# Contributing to GoalRush

First off, thank you for considering contributing to GoalRush! It's people like you that make GoalRush an incredible Open AGI Prediction Market.

### 1. Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check the **Issues** tab to see if someone else has already created a ticket. If not, go ahead and make one!

### 2. Fork & create a branch

If this is something you think you can fix, then fork GoalRush and create a branch with a descriptive name.

```bash
git checkout -b fix/your-branch-name
```

### 3. Implement your fix or feature

Make sure your code adheres to our strict "Hard Boundary Execution Architecture" when touching any AGI agent files. Do not grant the LLM direct payload access.

### 4. Make a Pull Request

At this point, you should switch back to your master branch and make sure it's up to date with GoalRush's master branch. Then push your branch to GitHub/GitLab and open a Pull Request.

Please provide a detailed description of what you changed so the maintainers can easily review it.
