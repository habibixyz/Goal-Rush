All notable changes to this project will be documented in this file.

## [Unreleased]

## [1.1.0] - 2026-06-25
### Added
- **GoalRush Open AGI Agent**: Autonomous Node.js agent integrating Llama-3 (Groq API) for decentralized prediction market trading.
- "Hard Boundary" execution architecture to prevent prompt-injection attacks.
- Auto-claiming compounding loop for the AGI agent.

## [1.0.0] - 2026-06-20
### Added
- Initial deployment of GoalRush MVP on OKX X Layer.
- Uniswap V4 Hook with `beforeSwap` match jackpot routing and `afterSwap` fee rebates.
- Keeper bot for automated match orchestration via ESPN sports data.
- React frontend dashboard for decentralized prediction market trading.
